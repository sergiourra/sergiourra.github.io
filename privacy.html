Política de Privacidad

Última actualización: 7 de noviembre de 2026

Alcance

Esta política aplica a la aplicación OAuth de uso personal registrada en Google Cloud bajo el proyecto "rclone", utilizada exclusivamente por el dueño de este sitio para acceder a sus propias cuentas de Google Drive y Dropbox a través del software rclone (https://rclone.org).

Datos que se recopilan

Esta aplicación no recopila, almacena ni comparte ningún dato de usuarios en servidores propios. No hay backend, base de datos ni servicios de terceros asociados.

Uso de los datos

El token OAuth se almacena únicamente y de forma local en el dispositivo del dueño de la aplicación (~/.config/rclone/rclone.conf) y se usa exclusivamente para sincronizar archivos entre sus propios dispositivos y sus propias cuentas de almacenamiento en la nube.

Compartición de datos

No se comparte ningún dato con terceros. No se usa la información para publicidad ni para ningún otro fin.
